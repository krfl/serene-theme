# Serene Theme for OpenCode

Eye-friendly color schemes for [OpenCode](https://opencode.ai) - the open source AI coding agent.

## Available Variants

All six Serene variants are available for OpenCode:

- **serene-night.json** - Classic dark mode
- **serene-day.json** - Classic light mode
- **serene-night-clarity.json** - Dark mode with enhanced visual distinction
- **serene-day-clarity.json** - Light mode with enhanced visual distinction
- **serene-night-focus.json** - Dark mode with high contrast
- **serene-day-focus.json** - Light mode with high contrast

## Installation

To use these themes with OpenCode, you can either:

1. **Select via command**: Use the `/theme` command in OpenCode to bring up the theme selector
2. **Configure in config file**: Add the theme to your OpenCode configuration

## Important Notes

OpenCode's theme system differs from Helix and VSCode in that it doesn't support per-token background colors. The Clarity and Focus variants have been adapted to work within OpenCode's capabilities:

- **Clarity variants** use subtle background colors for panels and UI elements to create visual distinction
- **Focus variants** use a minimalist color palette with higher contrast, emphasizing keywords, strings, and constants while keeping other elements neutral

All variants maintain Serene's core eye-friendly properties:
- Warm earth tones
- Reduced blue light (~20-30% vs 40-50% in standard themes)
- Optimal 10-11:1 contrast ratios (WCAG AAA compliant)
- Muted saturation to prevent eye strain

## Choosing a Variant

- **Classic** (Night/Day): Best for extended sessions and universal compatibility
- **Clarity** (Night/Day): Enhanced visual anchors with subtle backgrounds
- **Focus** (Night/Day): Maximum distinction with high contrast for intensive work

All variants share the same eye-friendly foundation and are suitable for reducing digital eye strain.
